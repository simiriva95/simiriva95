## Su di me
 
Costruisco interfacce web da diversi anni, con focus su architetture component-driven, design system scalabili e performance percepita. Mi muovo tra frontend e AI, esplorando come i modelli generativi possano integrarsi in prodotti reali — senza sacrificare accessibilità, manutenibilità o cura del dettaglio.
 
Un'interfaccia ben fatta è invisibile quando funziona, e memorabile quando non si limita a farlo.
 
---
 
## Cosa faccio
 
**Architettura frontend** — Design system riutilizzabili, librerie di componenti tipizzate, pattern composition-first. Tratto i componenti come API: documentate, versionabili, prevedibili.
 
**Performance** — Core Web Vitals, code splitting, ottimizzazione del bundle, rendering strategies (SSR / SSG / ISR), profiling di runtime.
 
**AI nel frontend** — UI conversazionali, streaming di token, gestione dello stato per esperienze generative, integrazione di SDK e protocolli (MCP).
 
**Accessibilità** — WCAG 2.1 AA, semantica HTML, ARIA, gestione del focus, navigazione da tastiera, screen reader testing.
 
**Motion & dettaglio** — Micro-interazioni con intento, transizioni che comunicano stato, ritmo visivo coerente.
