## Cosa faccio

**Architettura frontend** — Design system riutilizzabili, componenti tipizzati, composition-first. Tratto i componenti come API: documentate, versionabili, prevedibili.

**Performance** — Core Web Vitals, code splitting, bundle budget, SSR / SSG / ISR, profiling di runtime.

**AI nel frontend** — UI conversazionali, streaming di token, gestione dello stato per esperienze generative, integrazione SDK e MCP.

**Accessibilità** — WCAG 2.1 AA, semantica HTML, ARIA, gestione del focus, navigazione da tastiera, screen reader testing.

**Motion & dettaglio** — Micro-interazioni con intento, transizioni che comunicano stato, ritmo visivo coerente.

Un'interfaccia ben fatta è invisibile quando funziona, e memorabile quando non si limita a farlo.
